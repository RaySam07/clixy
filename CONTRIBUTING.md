# Contributing

Thanks for helping make Clixy better.

1. Fork, then `py -3.13 -m venv .venv && .venv\Scripts\activate && pip install -r requirements.txt`.
2. Run Clixy from source with `python app.py`.
3. Make your change with a test next to it, and run `python -m pytest`.
4. Open a pull request saying what changed and why; a screenshot or GIF helps
   for anything visual.

Good first contributions: a new pixel buddy in `theme.py`, a new kind of mark in
`drawing.py`, or a translation of the prompts in `ai.py`.
