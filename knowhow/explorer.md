- win+e opens it. ctrl+l (or alt+d) puts the cursor in the address bar: type a path, or shell:downloads, %appdata% and the like, to jump there.

## keys
- ctrl+t new tab · ctrl+w close the tab · ctrl+n new window · ctrl+shift+n new folder · f2 rename · ctrl+shift+c copy as path · alt+enter properties
- alt+up the folder above · alt+left and alt+right back and forward · ctrl+e or ctrl+f search · f5 refresh
- alt+p preview pane · alt+shift+p details pane · ctrl+mouse wheel bigger or smaller icons
- delete sends to the recycle bin; shift+delete deletes for good (warn them first)

## tricks
- hidden files or file name extensions: view > show > hidden items, or file name extensions
- zip: select the files, right-click > compress to zip · unzip: right-click the zip > extract all
- type cmd or powershell in the address bar to open one in this folder; or right-click empty space > open in terminal
- pin a folder: right-click it > pin to quick access (it shows under home)
- shift+right-click shows the full older menu (the same as show more options)
- sort and group from the sort and view menus in the toolbar
