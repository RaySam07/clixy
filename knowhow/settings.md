- win+i opens it; [OPEN:ms-settings:...] lands right on a page; the search box at the top left finds any setting by name.
- down the left: system, bluetooth and devices, network and internet, personalization, apps, accounts, time and language, gaming, accessibility, privacy and security, windows update.

## system > power and battery ([OPEN:ms-settings:batterysaver])
- battery level and time left, power mode (best power efficiency, balanced, best performance), energy saver (battery saver before 24h2), screen and sleep timeouts, and battery usage: a graph plus the apps using the most

## system > display ([OPEN:ms-settings:display])
- brightness, night light, hdr, scale, resolution, orientation, multiple displays (duplicate or extend, identify, rearrange)
- advanced display for the refresh rate · graphics for which gpu an app uses

## system
- sound: output and input device, volume mixer ([OPEN:ms-settings:apps-volume])
- notifications and do not disturb · storage (storage sense, cleanup recommendations) · multitasking (snap windows) · clipboard · about (device name, specs, rename this pc)

## bluetooth and devices
- add device for headphones and speakers (put them in pairing mode first) · printers and scanners · mouse · touchpad gestures · mobile devices (phone link)

## network and internet
- wi-fi (known networks, properties, view wi-fi security key) · mobile hotspot · airplane mode · vpn · proxy · data usage · advanced network settings (adapters, network reset)

## personalization
- background · colours (choose your mode: light, dark or custom; accent colour) · themes · lock screen · start · taskbar (taskbar behaviours: alignment left or centre, auto-hide)

## apps
- installed apps (sort by size, uninstall from the ···) · default apps (pick the app, then set default) · startup · optional features

## accounts, time, gaming, accessibility, privacy
- sign-in options (pin, fingerprint, face) · windows backup · other users · date and time (set automatically, time zone) · language and region · game mode
- text size, contrast themes, colour filters, narrator, magnifier, mouse pointer size · camera, microphone and location permissions per app · windows security

## windows update
- check for updates · pause updates · update history · advanced options > optional updates (drivers) · restart options
