- ctrl+shift+p the command palette runs any command by name; ctrl+p opens a file by name (type > for commands, @ for symbols, : for a line).

## keys
- ctrl+` the terminal · ctrl+shift+` a new terminal · ctrl+b side bar · ctrl+j the bottom panel · ctrl+\ split the editor · ctrl+w close the tab · ctrl+shift+t reopen it
- ctrl+shift+e explorer · ctrl+shift+f search all files · ctrl+shift+g source control · ctrl+shift+x extensions · ctrl+shift+d run and debug
- ctrl+, settings · ctrl+k ctrl+s keyboard shortcuts · ctrl+k ctrl+t colour theme · ctrl+k z zen mode · alt+z word wrap
- ctrl+/ comment the line · alt+up or down moves it · shift+alt+up or down copies it · ctrl+shift+k deletes it · shift+alt+f formats the file
- ctrl+d selects the next match · ctrl+shift+l every match · alt+click another cursor · ctrl+alt+up or down a cursor above or below
- f12 go to definition · alt+f12 peek · shift+f12 references · f2 rename a symbol · ctrl+. quick fix · ctrl+g go to a line · ctrl+shift+o go to a symbol
- f5 start debugging · f9 breakpoint · f10 step over · f11 step into · ctrl+shift+v markdown preview · ctrl+k v preview beside it
- ctrl+k ctrl+0 folds everything · ctrl+k ctrl+j unfolds

## tricks
- code . in a terminal opens that folder in vs code
