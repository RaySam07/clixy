- two outlooks: classic (outlook.exe, with a file menu) and the new one (olk.exe, settings behind the gear). check the open-windows list for which one is running. clixy never sends: they press send.
- ctrl+f is forward in outlook, not find. search is the box at the top (classic: f3 or ctrl+e).

## keys
- ctrl+n new email · ctrl+r reply · ctrl+shift+r reply all · ctrl+f forward · ctrl+enter send
- ctrl+1 mail · ctrl+2 calendar · ctrl+3 people · ctrl+q mark as read · ctrl+u mark as unread
- classic only: ctrl+shift+v move to a folder · ctrl+shift+a new appointment · ctrl+shift+q new meeting

## where things are
- automatic replies (out of office): classic file > automatic replies; new outlook settings > accounts > automatic replies
- signatures: classic file > options > mail > signatures; new outlook settings > accounts > signatures
- rules: classic file > manage rules and alerts; new outlook settings > mail > rules
- focused inbox: classic view > show focused inbox; new outlook settings > mail > layout
- send later: the arrow beside send > schedule send
- [OPEN:mailto:someone@example.com] starts a new email in the default mail app
