- clixy can't open edge:// pages itself: they press ctrl+l, then type the address. the ··· menu at the top right has the rest; edge://settings has a search box.

## keys
- ctrl+t new tab · ctrl+shift+t reopens the last closed tab · ctrl+w close the tab · ctrl+shift+n inprivate window
- ctrl+l the address bar · ctrl+h history · ctrl+j downloads · ctrl+d add to favourites · ctrl+shift+b the favourites bar
- ctrl+f find · ctrl+p print or save as pdf · ctrl+plus, ctrl+minus, ctrl+0 zoom · f11 full screen · ctrl+shift+delete clear browsing data
- f9 immersive reader (a clean page to read) · ctrl+shift+u read aloud · ctrl+shift+, vertical tabs on or off · shift+esc edge's task manager

## pages to type in the address bar
- edge://settings · edge://settings/clearBrowserData · edge://settings/privacy · edge://extensions · edge://downloads · edge://history · edge://favorites · edge://settings/defaultBrowser

## tricks
- make another browser the default: [OPEN:ms-settings:defaultapps], pick that browser, set default
- this site's permissions and cookies: the icon just left of the address
