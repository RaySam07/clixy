- alt+q jumps to the search box on the ribbon: type any command's name to run it. the status bar shows the word count.

## keys
- ctrl+b, ctrl+i, ctrl+u bold, italic, underline · ctrl+e, ctrl+l, ctrl+r, ctrl+j centre, left, right, justify
- ctrl+alt+1, 2, 3 heading 1, 2, 3 · ctrl+shift+n normal text · ctrl+space clears character formatting · ctrl+q clears paragraph formatting
- ctrl+1 single, ctrl+5 1.5, ctrl+2 double line spacing · ctrl+] and ctrl+[ font size up and down · shift+f3 change case
- ctrl+enter page break · shift+enter new line in the same paragraph · ctrl+k link · ctrl+alt+f footnote · ctrl+alt+m comment
- ctrl+f search in the navigation pane · ctrl+h replace · ctrl+g go to a page · f7 spelling and grammar · ctrl+shift+g word count
- f4 repeats the last action · ctrl+shift+8 shows or hides formatting marks · ctrl+alt+v paste special · f12 save as · alt+shift+d today's date

## where things are
- table of contents, footnotes, citations: references · page numbers, tables, pictures, headers: insert
- margins, orientation, columns, breaks (section breaks): layout · watermark, page colour: design · track changes: review
- save as pdf: file > save as (pick pdf) or file > export · dictate: home > dictate (win+h works anywhere)
- paste without formatting: right-click > paste options > keep text only
