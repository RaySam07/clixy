- whatsapp web is [OPEN:https://web.whatsapp.com] (in a browser tab); the desktop app comes from the microsoft store. clixy never sends a message for them: they type and send.
- link this computer: on the phone, whatsapp > settings (iphone) or ⋮ (android) > linked devices > link a device, then scan the qr code on screen.

## around the app
- find or start a chat: the search box above the chat list; a new chat: the new chat (pencil) icon at the top of the list
- a chat's info (media, mute, disappearing messages, block, report): click the name at the top of the chat
- archive, mute, pin, mark as unread or delete a chat: right-click it in the list (or hover and use its arrow)
- settings (privacy, notifications, chat wallpaper, theme): the gear at the bottom left in the newer layout, or the ⋮ above the chat list
- chat with a number without saving it: [OPEN:https://wa.me/NUMBER] with the country code and no +, spaces or dashes
