- alt+q jumps to the ribbon's search box: type any command's name. pressing alt shows key tips, letters for every ribbon button.

## keys
- ctrl+arrow jumps to the edge of the data · ctrl+shift+arrow selects to there · ctrl+home and ctrl+end · ctrl+space selects the column · shift+space the row
- ctrl+t makes a table · ctrl+shift+l filters on or off · alt+= autosum · f2 edit the cell · f4 while editing toggles $a$1 references
- ctrl+; today's date · ctrl+shift+; the time · ctrl+1 format cells · ctrl+shift+4 currency · ctrl+shift+5 percent
- ctrl+d fill down · ctrl+r fill right · ctrl+e flash fill (copies a pattern you start) · ctrl+enter fills every selected cell
- alt+enter a new line inside a cell · ctrl+` shows formulas · ctrl+page up or down switches sheets · shift+f11 new sheet
- ctrl+shift+plus inserts cells · ctrl+minus deletes them · ctrl+alt+v paste special (values only, transpose)
- alt, h, o, i autofits the column width · alt, w, f, f freeze panes · alt+f1 a chart of the selection

## where things are
- freeze panes (top row, first column): view > freeze panes · remove duplicates, text to columns, data validation (a dropdown list): data
- pivottable, charts: insert · conditional formatting, wrap text, merge and centre: home · protect sheet: review
- print area, fit to one page: page layout · select all blanks: ctrl+g > special > blanks
- xlookup works in microsoft 365 and excel 2021 and later
